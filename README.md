# Blue Archive Student Exporter

실행 중인 블루 아카이브 Steam 클라이언트에서 본인 계정의 로그인 응답을 읽어 학생 육성 정보를 CSV로 저장하는 실험용 도구입니다. Windows x64와 64비트 Python 3.10 이상이 필요합니다. 외부 Python 패키지는 사용하지 않습니다.

## 동작 방식

Windows의 `OpenProcess`, `VirtualQueryEx`, `ReadProcessMemory`로 클라이언트 메모리에 남아 있는 `Account_LoginSync` JSON을 찾습니다. 프로세스 메모리 읽기 권한만 요청하며, 메모리 쓰기·코드 주입·게임 파일 수정·게임 서버 요청을 하지 않습니다. 프록시나 인증서 설치도 필요하지 않습니다.

메모리에는 인증 정보 등 민감한 내용이 있을 수 있습니다. 스캐너는 읽은 메모리 덤프나 전체 로그인 응답을 파일로 저장하지 않으며, CSV에는 학생 육성 관련 열만 기록합니다. 스캔 과정에서 읽은 메모리는 도구 프로세스 안에서 일시적으로 처리됩니다.

기본 실행은 학생 이름을 붙이기 위해 [SchaleDB의 한국 서버 공개 학생 목록](https://schaledb.com/data/kr/students.json)을 한 번 다운로드합니다. 요청 URL은 고정되어 있고 계정 정보는 전송하지 않습니다. 이 연결을 원하지 않으면 `--offline`을 사용하세요. 공개 데이터는 저장소에 포함하지 않습니다.

## 실행

1. 본인 계정으로 Steam 클라이언트에 로그인해 로비까지 들어갑니다.
2. 로그인 직후 아래 명령을 실행합니다.

```powershell
python export_students.py --output students.csv
```

완전 오프라인 실행은 이름 대신 학생 ID를 표시합니다.

```powershell
python export_students.py --offline --output students-offline.csv
```

이미 다운로드한 SchaleDB 이름 목록은 `--names-json path/to/students.json`으로 지정할 수 있습니다. 여러 클라이언트가 실행 중이면 `--pid`로 대상 BlueArchive.exe를 지정하세요. 기존 CSV는 덮어쓰지 않습니다. 기본 권한으로 읽기가 거절되면 오류로 종료하며 보호 기능을 우회하지 않습니다.

## 저장되는 정보

학생 ID·이름·레벨·경험치·성급, 인연 랭크와 경험치, EX/기본/강화/서브 스킬 레벨, 전용무기 보유 여부·성급·레벨·경험치, 애용품 보유 여부·티어·레벨, 장비 3칸의 ID·티어·레벨, 체력/공격력/치유력 잠재력, 즐겨찾기와 로그인 응답 시각을 저장합니다. 총 32열이며 레벨, 성급, 이름 순으로 정렬합니다. Excel에서 한글을 읽을 수 있도록 UTF-8 BOM을 사용합니다.

계정 ID, 캐릭터의 계정별 내부 식별자, 세션 키, 친구 정보, 결제 정보는 CSV에 포함하지 않습니다. 재화나 미보유 학생은 내보내지 않습니다. 보유하지 않은 무기·애용품·장비는 0으로 표시하며, 보유 여부 열로 구분할 수 있습니다.

로그인 응답 시각은 서버의 .NET ticks 값을 그대로 날짜로 변환합니다. 이 값 자체에는 시간대가 없으므로 UTC 등 특정 시간대로 단정하지 않습니다.

## 한계와 확인 범위

- 로그인 당시 응답입니다. 로그인 후 육성한 내용은 반영되지 않을 수 있으므로 게임을 재시작하고 다시 로그인한 뒤 추출하세요.
- 로그인 JSON이 메모리에서 해제되거나 클라이언트 형식이 바뀌면 찾지 못할 수 있습니다. 실패하면 추정값을 만들어 저장하지 않습니다.
- 2026-09-27 한국 서버 Steam 클라이언트 버전 453174에서 확인했습니다. 다른 서버, 앱플레이어, 다른 빌드의 지원을 보장하지 않습니다.
- 초기 읽기 전용 스캐너로 로그인 응답을 추출했고 변환 결과를 검증했습니다. 정리한 최종 CLI의 라이브 읽기 재검증은 클라이언트가 종료되어 완료하지 못했습니다.
- CSV 검증과 실제 학생 상세 화면의 대조는 별개입니다. 개별 학생 화면과의 대조는 완료되지 않았습니다.
- `--snapshot`은 로컬 개발용입니다. 이미 보관 중인 로그인 응답의 **packet 객체** JSON을 읽습니다. 전체 응답 봉투가 아니며, 이 도구는 해당 원본을 생성하지 않습니다. 원본과 CSV를 저장소에 커밋하지 마세요.
